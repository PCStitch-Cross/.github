# PCStitch

> One named PCStitch chart. Finish the color. Leave a note the next person can read.

## Session Card

| Slice | What you do in PCStitch | What remains |
|-------|------------------------|--------------|
| Arrival | Open PCStitch and name today's sewing desk | A titled counted chart |
| Focus | Keep only the live grid on the PCStitch board | A short floss pin list |
| Check | Read PCStitch floss list before the next color | A confirmed pattern grid |
| Handoff | Mark finished colors inside PCStitch | A note for the next visit |

## How PCStitch Sits

PCStitch does not replace the hoop, the cloth, or the floss boxes you already own. It sits beside them as a named sewing desk for one job: which cross stitch chart is live, which floss list still matches the grid, and what the next person should read before the next color.

## Traffic Light

| Signal | On the PCStitch board | What you do |
|--------|----------------------|-------------|
| Green | Named chart, short live floss list | Continue the same grid |
| Amber | Two cloths mixed in one pattern grid | Split the set before a color |
| Red | No title, no note, floss unlabeled | Stop and name the chart first |
| Clear | Handoff written, live colors few | Close PCStitch and leave the desk |

## Open Order

1. Open the last PCStitch chart, not a new empty sewing desk.
2. Read the floss list and the last handoff.
3. Finish one visible color on the PCStitch pattern grid.
4. Write what changed, then close with fewer unlabeled floss codes than you found.

## Desk Fit

| Who | What PCStitch holds |
|-----|--------------------|
| Sewing desk | Counted chart and floss list for cloth you own |
| Shared desk | One PCStitch profile per person |
| Home hoop | Personal grids out of the shop stitch pile |

## After a Week

A week in PCStitch is not a thicker photo of someone else's cloth. It is the same title, a shorter live floss list, and a note that still makes sense before the next color. Take finished charts off the live set so the next visit starts on the grid that is still open.

## Sign-off

- [ ] The PCStitch workspace name is short enough to scan
- [ ] Only the live chart is on the board
- [ ] A second person can read the handoff
- [ ] The last PCStitch chart still opens after a restart

## Field Note

PCStitch is easier to trust when the sewing desk stays smaller than the pattern folder it came from. Name the chart, keep the live grid, finish one visible color, and write what changed.
